# 🧮 Calculadora em C

Projeto desenvolvido durante meus estudos de programação, com o objetivo de praticar lógica de programação e os fundamentos da linguagem C.

## 📌 Sobre o projeto

Esta calculadora funciona por meio de um menu interativo no terminal e permite realizar operações matemáticas.

## ⚙️ Funcionalidades

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- 📜 Histórico de cálculos
- 🧹 Limpeza do histórico
- 🔄 Opção de continuar os cálculos com o resultado anterior
- 🚪 Opção para encerrar o programa

## 🛠️ Tecnologias utilizadas

- Linguagem C
- GCC (compilador C)
- Linux
- Visual Studio Code

## ▶️ Como executar

1. Clone este repositório ou baixe o arquivo `calculadora.c`.
2. Abra o terminal na pasta do projeto.
3. Compile o programa:

```bash
gcc calculadora.c -o calculadora
```

4. Execute:

```bash
./calculadora
```

## 🎯 Objetivo educacional

Praticar variáveis, operadores matemáticos, estruturas condicionais, laços de repetição, menus interativos e manipulação de histórico.
